# WoodSheetLayout 2.2.6（Rhino 7 / Rhino 8）

面向木制拼装产品、激光切割刀模和 CAD 出图的一键铺平插件。本版不再只保留1.1.0的MaxRects，而是恢复普通命令从选择、分组、铺平到文档复制输出的完整1.1.0通道；自定义边界框、独立折弯件铺平和中文选项只加在外围。

## 普通排版：保持1.1算法

- 使用板件及其同组曲线、文字铺平后的**整体矩形包围盒 `FlatBounds`**。
- 使用1.1.0原有的 **MaxRects** 排版核心。
- 依次比较面积、最长边、宽度和高度四种排序。
- 每种排序比较最短边、最小剩余面积和左下角三种启发式，共12次快速方案。
- 自动比较0°/90°，选择板材张数少、排列紧凑且规整的结果。
- 优先排满已有板框；放不下才自动生成下一张同厚度板框。
- 不再提供真实轮廓精排、孔洞嵌套或自由角度搜索。
- 普通命令按照1.1.0原顺序寻找真实平面和厚度，不运行2.x的近似曲面扫描；近似平面分析仅供独立折弯命令使用。
- 普通Brep板面方向重新严格使用1.1的“曲线采样点到候选平面距离”判断，不再让修剪面ClosestPoint影响零件有效性。
- 普通命令直接使用 `GetObject(GroupSelect=true)` 返回的对象及其现有Group组装零件，不再递归追踪交叉组，避免把独立板件串成大组件。
- 普通平板把“铺平＋0°/90°旋转＋排版位移”合并为一次变换，并调用1.1.0原来的 `doc.Objects.Transform(source.Id, transform, false)` 直接复制原始Rhino对象。
- 只有Rhino实际返回新对象GUID才计为生成成功；不再使用“内存FlatGeometry→再次复制→通用Add”的2.x输出链。
- 每个已铺平零件建立唯一`WSL_PAIR`配对Group：原始木板、原始同组曲线及对应铺平副本共同加入该组。
- 不在原模型旁生成黄色问题编号或缺件文字；移动配对Group即可核对原件与副本。
- 配对Group只增加组成员关系，不移动原始模型，也不改变原图层和颜色。
- 再次运行排版时自动忽略带`FlatCopy`标记的旧铺平副本，避免重复排版。
- 普通排版自动跳过旧`FlatCopy`副本和旧`WoodSheetLayout_*`输出图层；折弯命令仍可补齐同组成员。
- `WoodSheetLayout`不再要求对象必须被识别为木板：Brep、Extrusion、Mesh、Surface、曲线、文字、块实例或其他可复制几何都会生成铺平副本。
- 1.1木板识别失败后，从对象平面、Brep曲面坐标架、网格面、块实例坐标或世界坐标中选择最薄方向，强制刚体放到世界XY。
- 厚度识别失败时优先读取`2mm`、`2.5mm`等图层名称；没有厚度信息也不会取消铺平。
- 超过A3/A4/Custom可用范围的对象不缩放、不遗漏，自动生成一张能够完整容纳它的加大边界框。
- 命令结束时分别核对“组数、识别数、排入数、实际生成数”；只有四项相同才报告全部铺平。
- 折弯件因不存在单一刚体铺平变换，继续使用独立的中性层展开输出，不影响普通排版通道。

FlatBounds只用于排版占位；插件复制输出的仍是原木板实体、切割线、孔线、刻线和文字，不会把零件变成矩形。

## 保留的少量优化

- A3：420 × 297 mm。
- A4：297 × 210 mm。
- Custom：自主输入完整边界框宽度和高度。
- `边框出血=4mm`：零件到边界框四周保留真实4mm。
- `零件间距=4mm`：零件矩形包围盒之间保持真实4mm。
- 可选择横向或纵向；可锁定木纹方向。
- 自动按实际厚度分类，一张排满后自动增加下一张。
- 曲线、文字与木板同组铺平，有曲线的一面朝上。
- 保留源图层、图层颜色、对象颜色、线型、打印属性和组关系。
- 原模型不移动、不删除、不改颜色，结果输出到独立图层。
- 状态栏显示进度，可按 `Esc` 取消。

## 中文选项

运行 `WoodSheetLayout` 后，中文版Rhino命令行显示：

| 中文选项 | 作用 | 默认值 |
| --- | --- | --- |
| `边界框` | A3 / A4 / 自定义 | A3 |
| `方向` | 横向 / 纵向 | 横向 |
| `自定义宽度` | Custom完整宽度（mm） | 420 |
| `自定义高度` | Custom完整高度（mm） | 297 |
| `零件间距` | 矩形包围盒之间距离（mm） | 4 |
| `边框出血` | 零件到边框四周距离（mm） | 4 |
| `木纹锁定` | 锁定后只用0°，不旋转90° | 否 |

英文版Rhino仍显示对应英文名称，保证脚本和跨语言兼容。中文选项使用RhinoCommon官方 `LocalizeStringPair` 本地化接口实现。

## 命令和快捷键

| 命令 | 功能 | 推荐别名 |
| --- | --- | --- |
| `WoodSheetLayout` | 所有选中对象组，显示中文参数选项 | `WSL` |
| `WSLayFlatA3` | 一键A3横向、4mm间距、4mm边框出血 | `A3P` |

## 独立折弯件铺平

普通 `WoodSheetLayout` 对所有选中对象执行刚体铺平；折弯件如需按中性层真实展开，仍应单独运行 `WSLayFlatBend`：

1. 选择厚度恒定的折弯木板和同组曲线。
2. 设置边界框、方向、间距、边框出血和`中性层系数`。
3. 默认 `中性层系数=0.5`，按木板厚度中间层计算展开长度。
4. 支持圆柱、圆锥和“直面＋弯曲面”的连续可展板件。
5. 平面段和弯曲段先组成连续皮肤，再整体偏移到中性层；铺平后公共接缝仍然相接。
6. 球面、马鞍面等双曲率对象不强行展开，只在命令行报告。
7. 展开后的零件仍使用矩形包围盒MaxRects进行规整排版。

### 2.2.0折弯样式

已按 `zhewan.3dm` 的四种实际建模方式调整：

- 紫色：折弯圆柱面与边缘卡口属于同一个修剪面。
- 红色：先创建折弯实体，再布尔卡口；主折弯面旁含有额外小圆柱面和侧壁面。
- 蓝色：`木板－折弯－木板`，一条连续面链中包含两个直面和一个折弯面。
- 绿色：书脊式 `木板－折弯－木板－折弯－木板`，连续面链中包含三个直面和两个折弯面。

为兼容这四类结构，折弯命令会：

- 忽略Brep底层法线方向相反造成的假断链。
- 对连续直面/曲面先整体偏移到 `NeutralFactor` 中性层，逐面偏移仅作为曲线映射和失败回退。
- 使用与板厚相关的接缝容差重新连接中性层和展开结果。
- 将展开后的多个共面面片重建为一个保留孔洞、卡口的平面板实体，再参加MaxRects排版。
- 命令行报告识别到的直面数和折弯面数，便于核对蓝色、绿色多段结构。

### 2.2.1卡口、镂空与表面曲线

已按 `zhewan2(1).3dm` 的复杂布尔折弯件修正：

- 不再只依赖中性层偏移后的修剪边界；从原实体连续皮肤提取每一条卡口、镂空和开槽边界，作为随动几何与中性层一起展开。
- 展开后重新连接闭合边界环，并据此重建带孔洞的平板实体，避免整体偏移时丢失布尔修剪环。
- 小面积但与主皮肤切向连续的面不再因面积阈值被遗漏。
- 同组压痕、图案、文字等附属曲线展开后统一放在平板上表面，不再停留在板厚中间层。
- 边界随动曲线只用于重建实体，不会作为额外刻线重复输出。

### 2.2.2孔槽实体布尔重建

已按 `zhewan3.3dm` 再次核对：2.2.1虽然提取了边界，但Rhino把多个闭合环建立为独立填充面，随后最大面选择仍得到无孔外板。本版改为：

- 从每个主皮肤面直接读取完整 `BrepLoopType.Inner`，不再把孔洞拆成零散边线。
- 外轮廓单独建立完整平板实体。
- 每个内环单独生成超过板厚的贯穿切割实体，并逐个执行 `Brep.CreateBooleanDifference`。
- 输出前检查平板顶面的真实内环数量；小于原实体内环数时停止输出，避免再次生成表面无孔的错误零件。
- 开口卡槽属于外轮廓，继续由展开后的外边界直接重建；封闭孔洞由实体布尔差生成。

### 2.2.3恢复稳定铺平并隔离孔洞边界

已检查 `zhewan3(1).3dm`：2.2.2错误输出约1.8万个对象，铺平实体却只剩约2.5mm宽的细条。原因是完整内环映射失败后，算法跳过正确主皮肤并选中了板厚侧面；边界碎片又干扰了附属曲线的随动索引。本版改为：

- 主表面铺平恢复2.2.1已验证的逐边修剪骨架，不再因单个孔洞失败尝试狭窄侧面。
- 卡口/镂空边界使用独立Unroller展开，不与压痕、图案和文字共用随动索引。
- 展开后重新连接碎边，以平面面积最大的闭合环作为真实外轮廓，其内部闭合环作为孔洞。
- 平面Brep按“外轮廓范围匹配＋内环数量最多”选择，不再仅按面积选择填满孔洞的面。
- Rhino 7若无法一次建立修剪孔洞，才使用贯穿切割实体逐孔布尔差。
- 孔洞重建失败时停止该件输出并保留原模型，不会再生成错误细条或上万条重复曲线。

### 2.2.4锁定真实板外轮廓

已检查 `zhewan4.3dm`：2.2.3不再产生海量重复曲线，但把一个约 `145.63 × 42.84mm` 的内部卡槽闭合环误当成整板外轮廓；原主皮肤的长度方向约为 `217mm`，因此输出仍不正确。本版改为：

- 始终以2.2.1展开面片的最大裸边闭合环作为整板尺寸基准。
- 随动边界只有与基准外环四周范围一致时，才允许替换外环并恢复开口卡槽细节。
- 其余位于外环内部的闭合环只作为镂空孔洞，不能再升级成整板。
- 实体生成后再次核对其XY范围必须与主展开面片一致；不一致就停止输出。
- 保留2.2.3的边界独立展开，继续避免表面曲线索引串位和重复生成。

### 2.2.5完整卡扣孔与真实入框范围

已按 `zhewan4(1).3dm` 核对：原折弯实体的主皮肤包含多个封闭卡扣孔；2.2.4逐边映射时，任意一段 `Pullback` 失败都会让对应孔静默消失。同时2.2.4虽然重建了完整大板，排版占位仍可能取到内部卡槽的小范围，导致整块铺平实体越出边界框。本版改为：

- 从每个主皮肤面直接读取完整 `BrepLoopType.Inner`，整环映射到中性层；整环失败才逐Trim回退。
- 逐Trim回退必须全部映射并重新闭合，才计为一个有效卡扣孔；缺一段就停止输出，不再生成少孔零件。
- 内环继续使用独立Unroller，不与压痕、图案和文字混排，保留2.2.3后的稳定输出数量。
- 重建前后分别核对“原主表面内环数、成功映射数、展开闭合环数、铺平实体真实内孔数”。
- `FlatBounds` 不再取随动边界中的最大闭合环，而是由最终铺平实体和上表面曲线的完整包围盒反算。
- MaxRects、0°/90°旋转与自动加大边界框全部使用该真实占位范围，确保所有输出几何与边框四周保持设置的4mm出血。

### 2.2.6直接映射原始修剪参数

2.2.5在测试件中准确检测到原主表面共有31个内环，但仍有7个复杂孔无法通过3D曲线 `Pullback` 映射到中性层，因此保护逻辑停止了输出。本版不取消孔数保护，而是补齐稳定映射通道：

- 优先读取每个孔原始 `BrepTrim` 的二维UV参数曲线，直接 `Pushup` 到保持同一参数化的中性层偏移面。
- 只有二维Trim通道不可用时，才回退到旧的三维边线 `Pullback/Pushup`。
- 平面段上的孔槽直接沿中性层法向平移，避免长圆孔、卡扣槽和大量布尔碎边的数值Pullback失败。
- 仍严格核对原主表面内环数与最终实体内孔数；不会用“取消保护”的方式输出少孔零件。

## 建模准备

1. 推荐每块木板使用有真实厚度的闭合Brep、Extrusion或Mesh；其他可复制对象也会强制铺平。
2. 一块木板和属于它的切割线、雕刻线、孔位线或文字放入同一个Rhino Group。
3. 不要把整套产品所有木板放进一个Group。
4. 普通平板使用 `WoodSheetLayout`；折弯件使用 `WSLayFlatBend`。

## 输出与问题标记

- 每个厚度建立独立板框，左上角显示厚度、板号、零件数量和矩形占位利用率。
- 每个零件和同组曲线在输出区重新组成独立Group。
- 普通命令仅在对象无效或完全无法复制时才在命令行报告；超过原板框的对象自动进入加大边界框。
- 整个命令支持一次Rhino撤销。

## 编译和安装

编译输出：

- `WoodSheetLayout-2.2.6-rhino7.zip`
- `WoodSheetLayout-2.2.6-rhino8.zip`
- `WoodSheetLayout-2.2.6-rhino7-rhino8.zip`

用户安装编译好的插件不需要安装.NET SDK。完整解压后运行 `install.ps1`；或者在Rhino输入 `_PlugInManager`，Rhino 7选择 `net48/WoodSheetLayout.rhp`，Rhino 8选择 `net8.0/WoodSheetLayout.rhp`。安装后完全重启Rhino。

如果Windows阻止加载：右键 `.rhp` → “属性” → 勾选“解除锁定”。
