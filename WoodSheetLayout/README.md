# WoodSheetLayout 2.1.2（Rhino 7 / Rhino 8）

面向木制拼装产品、激光切割刀模和 CAD 出图的一键铺平插件。本版严格回归 1.1.0 的普通排版骨架，只加入自定义边界框、独立折弯件铺平和中文命令选项。

## 普通排版：保持1.1算法

- 使用板件及其同组曲线、文字铺平后的**整体矩形包围盒 `FlatBounds`**。
- 使用1.1.0原有的 **MaxRects** 排版核心。
- 依次比较面积、最长边、宽度和高度四种排序。
- 每种排序比较最短边、最小剩余面积和左下角三种启发式，共12次快速方案。
- 自动比较0°/90°，选择板材张数少、排列紧凑且规整的结果。
- 优先排满已有板框；放不下才自动生成下一张同厚度板框。
- 不再提供真实轮廓精排、孔洞嵌套或自由角度搜索。
- 普通命令不再扫描曲面或判断折弯：测到板面和厚度后立即进入1.1铺平路径。

FlatBounds只用于排版占位；插件复制输出的仍是原木板实体、切割线、孔线、刻线和文字，不会把零件变成矩形。

## 保留的少量优化

- A3：420 × 297 mm。
- A4：297 × 210 mm。
- Custom：自主输入完整边界框宽度和高度。
- `边框出血=4mm`：零件到边界框四周保留真实4mm。
- `零件间距=4mm`：零件矩形包围盒之间保持真实4mm。
- 可选择横向或纵向；可锁定木纹方向。
- 自动按实际厚度分类，一张排满后自动增加下一张。
- 曲线、文字与木板同组铺平，有曲线的一面朝上。
- 保留源图层、图层颜色、对象颜色、线型、打印属性和组关系。
- 原模型不移动、不删除、不改颜色，结果输出到独立图层。
- 状态栏显示进度，可按 `Esc` 取消。

## 中文选项

运行 `WoodSheetLayout` 后，中文版Rhino命令行显示：

| 中文选项 | 作用 | 默认值 |
| --- | --- | --- |
| `边界框` | A3 / A4 / 自定义 | A3 |
| `方向` | 横向 / 纵向 | 横向 |
| `自定义宽度` | Custom完整宽度（mm） | 420 |
| `自定义高度` | Custom完整高度（mm） | 297 |
| `零件间距` | 矩形包围盒之间距离（mm） | 4 |
| `边框出血` | 零件到边框四周距离（mm） | 4 |
| `木纹锁定` | 锁定后只用0°，不旋转90° | 否 |

英文版Rhino仍显示对应英文名称，保证脚本和跨语言兼容。中文选项使用RhinoCommon官方 `LocalizeStringPair` 本地化接口实现。

## 命令和快捷键

| 命令 | 功能 | 推荐别名 |
| --- | --- | --- |
| `WoodSheetLayout` | 普通平板，显示中文参数选项 | `WSL` |
| `WSLayFlatA3` | 一键A3横向、4mm间距、4mm边框出血 | `A3P` |
| `WSLayFlatA4` | 一键A4横向、4mm间距、4mm边框出血 | `A4P` |
| `WSLayFlatBend` | 单独选择折弯件，中性层展开后按MaxRects排版 | `BFP` |

## 独立折弯件铺平

普通 `WoodSheetLayout` 为保证1.1速度，不再识别或展开折弯件；运行普通命令时请只选择平板。折弯件单独运行 `WSLayFlatBend`：

1. 选择厚度恒定的折弯木板和同组曲线。
2. 设置边界框、方向、间距、边框出血和`中性层系数`。
3. 默认 `中性层系数=0.5`，按木板厚度中间层计算展开长度。
4. 支持圆柱、圆锥和“直面＋弯曲面”的连续可展板件。
5. 平面段和弯曲段以公共接缝连续展开，铺平后仍然相接。
6. 球面、马鞍面等双曲率对象不强行展开，使用黄色编号提示。
7. 展开后的零件仍使用矩形包围盒MaxRects进行规整排版。

## 建模准备

1. 每块木板使用有真实厚度的闭合Brep、Extrusion或Mesh。
2. 一块木板和属于它的切割线、雕刻线、孔位线或文字放入同一个Rhino Group。
3. 不要把整套产品所有木板放进一个Group。
4. 普通平板使用 `WoodSheetLayout`；折弯件使用 `WSLayFlatBend`。

## 输出与问题标记

- 每个厚度建立独立板框，左上角显示厚度、板号、零件数量和矩形占位利用率。
- 每个零件和同组曲线在输出区重新组成独立Group。
- 无法识别、无法展开或超过板框的对象在源位置生成黄色 `WSL-001` 编号。
- 整个命令支持一次Rhino撤销。

## 编译和安装

编译输出：

- `WoodSheetLayout-2.1.2-rhino7.zip`
- `WoodSheetLayout-2.1.2-rhino8.zip`
- `WoodSheetLayout-2.1.2-rhino7-rhino8.zip`

用户安装编译好的插件不需要安装.NET SDK。完整解压后运行 `install.ps1`；或者在Rhino输入 `_PlugInManager`，Rhino 7选择 `net48/WoodSheetLayout.rhp`，Rhino 8选择 `net8.0/WoodSheetLayout.rhp`。安装后完全重启Rhino。

如果Windows阻止加载：右键 `.rhp` → “属性” → 勾选“解除锁定”。
