# Wood Sheet Layout 1.1（Rhino 7 / 8）

面向木制拼装产品、激光切割刀模与 CAD 出图的一键铺平排版插件。插件不会移动原模型，而是在原模型右侧生成铺平副本和 A3/A4 边界框。

## 主要功能

- 木板及与木板打组的刀线、雕刻线、孔位线一起铺平。
- 自动寻找板件最大平面，并从实体几何测量实际木板厚度。
- 自动判断同组曲线靠近哪一面，铺平后保证曲线所在面朝上。
- 厚度相差不超过 `0.15 mm` 的板件自动归为同一厚度批次。
- 相同厚度优先排入连续的同类边界框；单张放不下时自动增加下一张同厚度边界框。
- A3：`420 × 297 mm`；A4：`297 × 210 mm`，默认横向。
- 板件之间保持 `4 mm`，板件与边界框也保留 `4 mm`。
- 使用多排序策略 MaxRects 紧凑排版，并自动比较 0°/90°，尽量把每张板排满、对齐整齐。
- 每张边界框左上角自动标注实际厚度，例如 `2mm`、`2.5mm`。
- 原图层、图层颜色、对象颜色、线型和打印属性随副本保留。
- 每块板及其附属曲线在输出区重新组成独立 Rhino Group。
- 原模型不移动、不删除；整个操作支持一次 Rhino 撤销。

## 建模准备规则

为了稳定识别，每块木板建议这样组织：

1. 木板使用有实际厚度的闭合 Brep、Extrusion 或 Mesh，不要只有一张零厚度曲面。
2. 一块木板与属于它的切割线、雕刻线、文字定位线放入同一个 Rhino Group。
3. 不要把整套产品的所有木板放在同一个 Group；应当“一块木板 + 它的曲线”为一组。
4. 曲线可以位于木板表面或稍微离开表面，插件会使用与木板完全相同的变换一起铺平。
5. 文档单位可以是毫米、厘米或英寸；插件会把 A3/A4 和 4 mm 自动换算到当前文档单位。

## 使用方法

### 可选 A3/A4

1. 运行 `WoodSheetLayout`。
2. 选择 `A3` 或 `A4`；直接回车默认为 A3。
3. 框选或逐个选择需要排版的木板组，回车完成。
4. 插件在原模型右侧生成铺平副本，并按厚度建立彩色边界框图层和左上角厚度标注。

### 一键固定纸张

| 命令 | 作用 | 推荐 Rhino 别名 |
| --- | --- | --- |
| `WoodSheetLayout` | 运行时选择 A3/A4 | `WSL` |
| `WSLayFlatA3` | 直接按 A3、4 mm 间距铺平 | `A3P` |
| `WSLayFlatA4` | 直接按 A4、4 mm 间距铺平 | `A4P` |

在 Rhino `工具 → 选项 → 别名` 中添加，例如 `A3P = _WSLayFlatA3`，即可输入 `A3P` 回车快速排版。

## 输出规则

- 输出边界框按厚度建立图层，例如 `WSL_边界框_2.00mm`、`WSL_边界框_2.50mm`。
- 每块铺平副本重新分组，组名包含厚度、板号和原零件名。
- 超过 A3/A4 可用范围的板件不会强行缩放，命令行会列出未排入的零件。
- 自动排版只做刚体旋转与位移，绝不会改变零件比例或曲线长度。

## 激光切割提醒

插件按模型的实际实体厚度分类，不会自动修改插槽公差和激光切缝。2 mm 名义板材也可能不是精确 2.00 mm；正式下料前仍应先切公差测试片，再确定插槽宽度、孔径和焦点补偿。

## 编译

Windows 环境需要 .NET 8 SDK 和 .NET Framework 4.8 Developer Pack：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出：

- `dist\net48\WoodSheetLayout.rhp`：Rhino 7。
- `dist\net8.0\WoodSheetLayout.rhp`：Rhino 8。
- `dist\WoodSheetLayout-1.1.0-rhino7-rhino8.zip`：双版本安装包。

用户直接安装编译好的 `.rhp` 不需要安装 .NET SDK。

## 安装

先完整解压 ZIP，不要在压缩包里直接双击 `.rhp`。可运行 `install.ps1`，也可以在 Rhino 中运行 `_PlugInManager` → `安装`，选择对应版本的 `.rhp`，然后完全重启 Rhino。

如果 Windows 阻止加载：右键 `.rhp` → `属性` → 勾选 `解除锁定/Unblock`。

## 1.1 边界

- 当前版本使用多策略 MaxRects 矩形紧凑排版；比顺序货架排版更密、更整齐，但仍不是按不规则轮廓互相穿插的 UV/异形最密套料算法。
- 自动厚度识别要求组内至少有一个具有实际厚度的板件实体。
- 同一个 Rhino Group 被视为同一块刚性板件；分组错误会导致多块板被一起铺平。
- 块实例可以作为附属对象一起复制，但 1.1 不从嵌套块定义内部测量木板厚度。
