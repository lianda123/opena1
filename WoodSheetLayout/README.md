# WoodSheetLayout 2.0.2（Rhino 7 / Rhino 8）

面向木制拼装产品、折弯木板、激光切割刀模和 CAD 出图的一键铺平套料插件。2.0 从矩形包围盒排版升级为真实外轮廓排版，并加入孔洞嵌套、木纹方向锁定和折弯件中性层展开。

插件采用非破坏方式：**不修改原模型，不移动原对象，不删除原对象，也不改变原对象的组、图层和颜色。** 所有结果放入一个新的 `WoodSheetLayout_2.0_日期时间` 独立图层树中。

## 2.0.2 主要功能

- 按零件真实外轮廓检测碰撞，不再以矩形包围盒作为最终碰撞边界。
- 支持零件放入其他零件满足4 mm安全距离的大孔洞中。
- 一张板排满后自动增加下一张，并继续按相同厚度分页。
- 排版固定只尝试0°/90°；不再进行15°自由旋转穷举，减少候选数量和运行时间。
- `GrainLock=Yes` 时锁定木纹方向，不允许排版算法旋转零件。
- A3、A4和Custom自定义矩形长宽；支持横向和纵向。
- `PartGap=4`：零件真实轮廓之间保持4 mm。
- `FrameMargin=4`：零件到边界框四周保留4 mm出血/安全距离。
- 文档采用毫米、厘米或英寸时，所有毫米参数会自动换算为真实物理尺寸。
- 自动寻找曲线/文字靠近的板面，使附属曲线面朝上。
- 自动检测文字法向；必要时修正文字朝下或镜像方向。
- 平板使用刚体变换铺到世界XY；曲线、孔线、雕刻线和文字随板输出。
- 折弯板根据厚度中间层展开，默认 `NeutralFactor=0.5`。
- 支持“直面＋弯曲面”以及“直—弯—直”的连续板件：以公共接缝为锚点整体展开，铺平后仍保持相接。
- 球面、马鞍面等双曲率对象或展开面积变化超过2%的对象不会强制变形，而是在原位置增加黄色问题编号。
- 每张板显示厚度、板号、零件数和真实轮廓利用率。
- 命令行列出板材数量、孔洞嵌套、未排入零件和铺平失败对象。

## 边界框

| 类型 | 尺寸 |
| --- | --- |
| A3 | 420 × 297 mm |
| A4 | 297 × 210 mm |
| Custom | 输入任意长度和宽度 |

默认横向。边界框内部四周保留4 mm，因此A3横向默认可用区域为412 × 289 mm。Custom输入的是完整边界框外尺寸，插件会在其内部扣除 `FrameMargin`。

## 折弯件中性层展开

对于厚度恒定的圆柱、圆锥或连续可展折弯木板，插件会：

1. 识别闭合实体的内外主表面和实际厚度。
2. 选择曲线/文字所在的一侧作为上表面参考。
3. 将该表面向木板内部偏移 `厚度 × NeutralFactor`。
4. 把得到的中性层曲面与附属曲线一起展开至世界XY。
5. 使用中性层真实外轮廓参加套料。
6. 尝试将平面中性层恢复为同厚度的平直实体；失败时至少输出中性面和切割轮廓。

### 直面与弯曲面的连续展开

当同一个厚度恒定实体由平面段和圆柱/圆锥等可展弯曲段连接组成时，插件不会分别铺平各个面：

1. 自动判断实体沿平面法向的总深度是否明显大于真实板厚，避免把混合折弯件误判成普通平板。
2. 收集共享接缝且切向连续的平面段、弯曲段，先组成一个连续主表面链。
3. 整条表面链统一偏移到中性层，而不是对直面和弯曲面生成互不相关的结果。
4. 以最大的直面作为展开方向基准，弯曲段从原公共接缝开始按中性层真实长度展开。
5. 展开后检查所有面的连接图；如果公共接缝断开，就停止输出并生成黄色编号，不会留下看似正确但实际分离的刀模。

因此，原模型中的“直面—弯曲面”相接关系在世界XY铺平结果中保持不变；多段“直—弯—直”也会沿连续接缝一起铺平。

默认：

```text
NeutralFactor = 0.5
中性层半径 = 内半径 + 厚度 × 0.5
展开长度 = 中性层半径 × 弯曲角度（弧度）
```

例如2 mm木板默认在距离内表面1 mm的位置计算展开长度。如果实物折弯测试出现固定长度误差，可以把K值调整为0.45、0.48等。

折弯面上的Rhino文字会转换成轮廓曲线再随中性层展开，便于激光刻线。双曲率曲面没有无变形的精确平面展开，因此2.0选择跳过并标记，不会偷偷拉伸零件。

## 使用方法

1. 每块木板实体与属于它的切割线、雕刻线、孔位线或文字放在同一个 Rhino Group。
2. 不要把整套产品所有木板放进同一个 Group；建议“一块木板＋附属曲线”为一组。
3. 运行 `WoodSheetLayout`。
4. 设置命令行选项，回车。
5. 选择木板组，回车完成。

### 命令行选项

| 选项 | 作用 | 默认值 |
| --- | --- | --- |
| `Sheet` | A3 / A4 / Custom | A3 |
| `Orientation` | Landscape / Portrait | Landscape |
| `CustomWidth` | Custom完整宽度（mm） | 420 |
| `CustomHeight` | Custom完整高度（mm） | 297 |
| `GrainLock` | 锁定木纹方向，禁止旋转 | No |
| `PartGap` | 零件真实轮廓间距（mm） | 4 |
| `FrameMargin` | 零件到边界框距离（mm） | 4 |
| `NeutralFactor` | 折弯件中性层系数 | 0.5 |

普通模式只检查0°与90°两个方向。木纹方向必须一致的椴木板、胶合板建议设置 `GrainLock=Yes`，此时只检查0°，速度最快。

### 快速命令

| 命令 | 作用 | 推荐别名 |
| --- | --- | --- |
| `WoodSheetLayout` | 完整参数设置 | `WSL` |
| `WSLayFlatA3` | A3横向、4 mm间距/边距、0°/90° | `A3P` |
| `WSLayFlatA4` | A4横向、4 mm间距/边距、0°/90° | `A4P` |

## 输出图层

每次运行都会创建新的独立图层树：

```text
WoodSheetLayout_2.0_日期时间
├─ 2.00mm_第01张
│  ├─ 边界框与统计
│  ├─ 原图层_切割线
│  └─ 原图层_雕刻线
├─ 2.00mm_第02张
└─ 问题标记_黄色
```

复制结果会重新建立组，并继承源对象名称、对象颜色、线型和打印属性。源图层会在输出板框下建立同色副本图层，从而既保留视觉信息，又不把结果混回原模型图层。

## 黄色问题编号

以下情况不会强行处理，会在源对象附近增加 `WSL-001` 形式的黄色TextDot：

- 没有实际厚度的零曲面木板。
- 厚度无法稳定识别。
- 非可展双曲率曲面。
- 中性层偏移或多面连接失败。
- 展开前后面积误差超过2%。
- 零件超过当前板框扣除4 mm边距后的可用区域。

问题标记和输出结果都是新对象，原模型保持不变，整个命令支持一次撤销。

## 编译与版本

Windows编译环境：.NET 8 SDK与.NET Framework 4.8 Developer Pack。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出：

- `dist\net48\WoodSheetLayout.rhp`：原生Rhino 7版本。
- `dist\net8.0\WoodSheetLayout.rhp`：原生Rhino 8版本。
- `dist\WoodSheetLayout-2.0.2-rhino7.zip`。
- `dist\WoodSheetLayout-2.0.2-rhino8.zip`。
- `dist\WoodSheetLayout-2.0.2-rhino7-rhino8.zip`。

用户安装编译好的 `.rhp` 不需要安装.NET SDK。

## 安装

先完整解压ZIP，不要直接在压缩包内运行脚本。右键 `install.ps1`，选择“使用PowerShell运行”；或在Rhino中运行 `_PlugInManager` → `安装`，选择对应版本目录中的 `WoodSheetLayout.rhp`，然后完全重启Rhino。

如果Windows阻止加载：右键 `.rhp` → `属性` → 勾选 `解除锁定/Unblock`。

## 生产提醒

插件负责铺平、套料和厚度分类，不会自动修改插槽公差与激光切缝。2 mm名义板材可能并非精确2.00 mm；折弯中性层K值也会随木材、含水率和折弯工艺变化。正式下料前仍建议先切公差与折弯长度测试片。
