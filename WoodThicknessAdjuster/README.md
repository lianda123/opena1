# WoodThicknessAdjuster 1.2.0（Rhino 7 / Rhino 8）

点击平直木板零件，自动识别当前板厚并调整为常用胶合板厚度。有相邻叠层板时默认保持贴合面；没有贴合关系时保持点击的主表面，只向另一侧增加或减少厚度，避免板面刀线、印刷面和装配基准漂移。

1.1.0新增“装配贴合”：当两块平行木板原本面贴面叠放，或调整后出现不超过5mm的小间隙时，插件优先把原贴合面作为主表面。连续点击第二块木板时，它会自动回贴第一块木板表面，不再因两次点击了不同外侧面而留下缝隙。与木板同组并位于板面的曲线、文字和点使用完全相同的缩放与回贴变换。

1.1.1新增“命令内撤回”：连续调整木板时无需先结束命令，可直接点击命令行的`撤回上一步（UndoLast）`，逐块恢复上一块木板及其同组附属对象的原几何和原属性。可以连续撤回多步，也支持同一块木板被多次调整后逐步退回。

1.2.0新增“指定目标面”：先点击需要调整板厚的木板，再直接点击另一零件的平面，调整后的木板会以最靠近目标面的主表面贴合过去。目标面若是曲面、木板自身表面或与板厚主表面不平行，插件会拒绝执行，避免侧面被误判为不动面。视窗用绿色标记调整板贴合面、蓝色标记目标面，完成后检查面间距与投影重合率，并在异常位置显示红色警告。

## 支持的板厚

- 1.5mm
- 2mm
- 2.5mm
- 3mm
- 4mm
- 5mm
- 0.1–50mm自定义厚度

## 主命令

运行 `WSAdjustThickness`：

1. 在命令行选择目标板厚。
2. 选择`保持点击面`或`中心对称`，并设置`装配贴合=自动贴合/指定目标面/关闭`。
3. 设置`贴合移动坐标=物体厚度轴/世界X轴/世界Y轴/世界Z轴`；通常使用默认的物体厚度轴。
4. 回车进入连续调整模式。
5. 自动贴合时直接点击木板；指定目标面时先点木板，再点另一零件上需要贴合的平面。
6. 继续点击叠放的第二块及后续零件；如需退回，点击命令行`撤回上一步（UndoLast）`，可重复多次。
7. 回车或Esc结束；命令结束后仍可用Rhino常规撤销退回整次命令。

插件会先确认点击点位于哪一张真实修剪面，再寻找它的平行对面并以两面间距作为原板厚。大板面即使被卡扣孔、槽或镂空切碎，也不会再被完整侧面抢作不动面；点击恰好落在共用边线附近时优先面积更大的板面。只有点击点不在木板面上（例如点击同组文字或曲线）时，才回退到面积与间距自动识别。变换只发生在厚度方向，木板平面内的长度、宽度、卡扣宽度和孔位不缩放。

## 装配贴合规则

- `自动贴合`默认开启，并优先于“保持点击面/中心对称”。检测到贴合关系时，两块板以自己的接触面作为共同装配基准。
- `指定目标面`不依赖自动搜索和零件点击顺序，适合叠层不同板厚、邻近零件较多或必须指定某一装配基准面的情况。
- `物体厚度轴`沿木板自身板厚方向移动；世界X/Y/Z轴用于必须保持某个世界坐标方向的装配。若所选世界轴与目标面平行，插件会停止当前零件并提示更换移动轴。
- 原本已经接触的平行主表面会直接锁定；若先前缩放造成小间隙，宽面积重叠且距离不超过5mm时会自动回贴。
- 连续操作时优先回贴刚刚调整的上一块木板，适合按“第一块→第二块→第三块”的顺序处理叠层结构。
- 不希望自动吸附的独立零件，可在`WSAdjustThickness`参数中选择`装配贴合=关闭`，恢复1.0.1的点击面逻辑。
- 垂直插接、折弯板和没有平行主表面的零件不会被当作叠层贴合处理。

## 贴合标记与检查

- 绿色点和法线表示调整板用于贴合的主表面，蓝色点和法线表示用户指定或自动识别的目标面，橙线表示移动关系。
- 调整后输出面间距（毫米）与投影重合率；同时满足接触公差和投影重合才显示绿色“通过”，否则在对应位置显示红色“警告”。
- 检查只验证面贴合关系，不代替卡扣深度、运动间隙和实体碰撞检查。

| `WSAdjustThickness` | 参数可选 | `WTA` |
| `WSThickness15` | 1.5mm | `WT15` |
| `WSThickness20` | 2mm | `WT20` |
| `WSThickness25` | 2.5mm | `WT25` |

快捷命令跳过参数面板，直接进入连续点击模式，并默认开启自动贴合；没有相邻贴合板时仍保持点击面不动。

## 组与属性

- 点击的木板若与曲线、文字或点位处于同一Rhino Group，这些附属对象会使用同一厚度缩放与回贴变换。
- 一个Group包含多块木板时，只带动位于当前木板主表面附近的曲线、文字和点，避免把另一块板的表面线带走。
- 未与木板打组的曲线不会自动移动，防止误改独立刀线；使用前请将木板与自己的表面曲线打组。
- 组内其他实体、网格和块不会被连带缩放，避免破坏机构零件。
- 保留对象图层、颜色、名称、材质和Group关系。
- 直接修改原零件，不生成重复副本；命令运行中可逐块`撤回上一步`，命令结束后可用Rhino常规撤销恢复整次操作。

## 当前安全范围

- 支持具有真实厚度、两张平行主表面的闭合`Brep`或`Extrusion`平直木板。
- 暂不处理折弯板、双曲率实体、开放曲面、Mesh或组内含多块木板的复杂组件。
- 非均匀缩放会改变侧壁、倒角和厚度方向的圆角高度；板面内轮廓保持不变。
- 调整装配件后仍应检查卡扣深度、轴孔长度和运动间隙。

## 安装

1. 完整解压ZIP。
2. 运行`install.ps1`；默认同时安装Rhino 7和Rhino 8版本。
3. 完全重启Rhino。

也可以在`PlugInManager`中手动安装：Rhino 7选择`net48/WoodThicknessAdjuster.rhp`，Rhino 8选择`net8.0/WoodThicknessAdjuster.rhp`。
