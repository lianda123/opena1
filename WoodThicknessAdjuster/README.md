# WoodThicknessAdjuster 1.0.0（Rhino 7 / Rhino 8）

点击平直木板零件，自动识别当前板厚并调整为常用胶合板厚度。默认保持点击的主表面不动，只向另一侧增加或减少厚度，避免板面刀线、印刷面和装配基准漂移。

## 支持的板厚

- 1.5mm
- 2mm
- 2.5mm
- 3mm
- 4mm
- 5mm
- 0.1–50mm自定义厚度

## 主命令

运行 `WSAdjustThickness`：

1. 在命令行选择目标板厚。
2. 选择`保持点击面`或`中心对称`。
3. 回车进入连续调整模式。
4. 点击木板时，尽量点在希望保持位置不变的那张大板面上。
5. 继续点击其他零件；回车或Esc结束。

插件自动寻找面积最大、距离最小的一对平行主表面，并用其间距作为原板厚。变换只发生在厚度方向，木板平面内的长度、宽度、卡扣宽度和孔位不缩放。

## 快捷命令

| 命令 | 目标板厚 | 推荐别名 |
| --- | ---: | --- |
| `WSAdjustThickness` | 参数可选 | `WTA` |
| `WSThickness15` | 1.5mm | `WT15` |
| `WSThickness20` | 2mm | `WT20` |
| `WSThickness25` | 2.5mm | `WT25` |
| `WSThickness30` | 3mm | `WT30` |
| `WSThickness40` | 4mm | `WT40` |
| `WSThickness50` | 5mm | `WT50` |

快捷命令跳过参数面板，直接进入连续点击模式，并默认保持点击面不动。

## 组与属性

- 点击的木板若与曲线、文字或点位处于同一Rhino Group，且组内只有一个可识别木板实体，这些附属对象会使用同一厚度变换。
- 组内其他实体、网格和块不会被连带缩放，避免破坏机构零件。
- 保留对象图层、颜色、名称、材质和Group关系。
- 直接修改原零件，不生成重复副本；整次命令可用一次Rhino撤销恢复。

## 当前安全范围

- 支持具有真实厚度、两张平行主表面的闭合`Brep`或`Extrusion`平直木板。
- 暂不处理折弯板、双曲率实体、开放曲面、Mesh或组内含多块木板的复杂组件。
- 非均匀缩放会改变侧壁、倒角和厚度方向的圆角高度；板面内轮廓保持不变。
- 调整装配件后仍应检查卡扣深度、轴孔长度和运动间隙。

## 安装

1. 完整解压ZIP。
2. 运行`install.ps1`；默认同时安装Rhino 7和Rhino 8版本。
3. 完全重启Rhino。

也可以在`PlugInManager`中手动安装：Rhino 7选择`net48/WoodThicknessAdjuster.rhp`，Rhino 8选择`net8.0/WoodThicknessAdjuster.rhp`。
