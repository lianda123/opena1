# 测试清单

## Rhino 7

- [ ] `net48` Release 构建成功。
- [ ] 通过 PlugInManager 加载 `.rhp`，重启后无报错。
- [ ] `PMTimeline` 打开停靠面板。
- [ ] 多选 Brep / Mesh / Curve 可转换为一个动画块。
- [ ] 创建 0 帧与 60 帧关键帧，拖动时间轴正确插值。
- [ ] 设轴心后，块围绕指定轴心旋转。
- [ ] 平滑、线性、阶梯插值结果不同且符合预期。
- [ ] 在已有关键帧上切换插值后立即生效，无需再次点击“插入/更新帧”。
- [ ] 时间轴线段以不同颜色区分平滑、线性和阶梯。
- [ ] 复制、粘贴、拖动、删除关键帧可用。
- [ ] 保存、关闭、重新打开 `.3dm` 后关键帧仍在。
- [ ] 播放结束后可以继续使用 Gumball 编辑并覆盖关键帧。
- [ ] 已打组对象使用 `PMTAddGroupPart` 时只转换所选零件，同组未选零件保持不变。
- [ ] 设置父级后，子级继承父级位移/旋转，同时保留自身关键帧。
- [ ] 两级以上父子关系按树形显示并正确递归求值。
- [ ] 自身父级、间接循环父级均被拒绝。
- [ ] 外啮合 20:40 齿轮在主动件转动 360° 时从动件反向转动 180°。
- [ ] 主动件只使用 Gumball 绕所选轴旋转并卡帧时，从动件仍可正确转动。
- [ ] 内啮合 20:40 在主动件转动 360° 时从动件同向转动 180°。
- [ ] 默认相位在建立约束瞬间不造成从动件跳动。
- [ ] 多级齿轮串联传动正确，A→B→A 循环约束被拒绝。
- [ ] 三个快速按钮均只要求选择主动件、从动件并输入齿数/比例，不询问相位。
- [ ] 删除父轨道时，子轨道解除父级且插件不报错。
- [ ] 0.1 版 `.3dm` 数据可读取，保存后升级且关键帧不丢失。
