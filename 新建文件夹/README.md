# ProductMotion Timeline 0.4.10（Rhino 7 / 8）

面向产品机构动态演示的 Rhino 关键帧时间轴插件。0.4.10 取消底部 DockBar，Rhino 7/8 均恢复标准侧边面板；完整保留 0.4.8 的撤回/重做、滚动与齿轮撤回防复制修复，并保留侧边轨道自适应容量。

界面预览：[docs/UI_PREVIEW.svg](docs/UI_PREVIEW.svg)

## 0.4.10 主要改进

- Rhino 7、Rhino 8 都恢复标准 Rhino 标签面板，不再创建、移动或强制停靠到窗口底部。
- `PMTimeline` 只负责打开时间轴侧边面板；面板继续沿用 Rhino 自己保存的左侧、右侧或浮动位置。
- 侧边轨道区根据可用高度自动扩大到 260–600px，可显示约 9–22 条轨道，保留 0.4.7 接近的轨道容量。
- 鼠标位于轨道区时滚轮浏览轨道；鼠标位于插件其他区域时滚动整个页面。
- 不再依赖 `RhinoWindows` 或 WinForms DockBar，Rhino 7/8 界面结构重新统一。

### 0.4.8 撤回与交互改进

- 关键帧撤回：插入、删除、数值编辑、批量粘贴和框选整体移动都可使用 Rhino `Undo/Redo`。
- 框选的多个关键帧作为一个撤回步骤，保留彼此间距。
- 一主多从、串联和同轴批量绑定作为一个撤回步骤，撤回后关系线和文字同步消失。
- 齿轮撤回不复制：Block 姿态更新改用 Rhino 原生单次变换，撤回不再恢复出额外副本。
- 鼠标在轨道中滚轮只浏览轨道，鼠标在其他位置时滚动整个插件页面。

- 轨道和 Rhino 物体现在双向联动：点击轨道会亮起对应物体，在视口选中动画 Block 也会自动定位并亮起对应轨道。
- 右键框选、`Shift` 加选或 `Alt` 减选后，拖动任意一个已选关键帧，全部已选帧会按同一帧差整体移动并保持原间距。
- 复制的单个、部分或全部关键帧可粘贴到任意目标轨道；最早复制帧对齐当前播放头，目标位置已有关键帧时直接覆盖并明确统计。
- 绑定外啮合、内啮合、同轴或一主多从时，只建立传动关系，不立即重算当前帧，因此不会擅自移动齿轮。
- 绑定成功时命令行会明确显示“绑定过程未移动零件”，便于区分“建立关系”和“播放/重算姿态”。
- 未正式卡动作帧的生成齿轮，绑定前会把 Gumball 当前摆位和轴心作为基础姿态；后续播放也不会跳回刚生成的位置。
- 打开时间轴或开始绑定时，会自动清理旧文件中 Block 变换矩阵的非仿射残差，保持当前可见摆位不变。
- 关系图使用齿轮当前显示轴心重绘，文字同时显示传动类型、主从名称、齿数和比例；绿/黄/红分别表示正常、警告和错误。

## 0.4.6 主要改进

- 点击轨道行或轨道名会立即选中对应 Rhino 动画物体；当前轨道显示蓝色边条和圆点，避免看不出正在编辑哪个零件。
- 双击关键帧会切换到该帧，并在“关键帧属性”栏显示移动 X/Y/Z、连续轴旋转角度和缩放 X/Y/Z；修改数值会立即更新该帧和视口。
- 在关键帧区域按鼠标右键拖框可框选关键帧；`Shift` 增加选择，`Alt` 从现有选择中减去，也可一键选择当前轨道全部关键帧。
- 可复制单个、部分或全部关键帧，并粘贴到一个或多个所选 Rhino 物体；已支持任意位置覆盖粘贴。
- 复制的位移、旋转和缩放是相对轨道基础姿态，应用到其他部件后可直接复用动作；超过原结束帧时会自动延长时间轴。

### 0.4.5 同轴复合齿轮

- 新增“同轴复合齿轮”按钮和 `PMTSameShaft` 命令，一次可把多个同轴零件刚性锁定到当前主动轨道。
- 同轴上下齿轮的角速度固定为 1:1，不会错误套用上下齿轮的齿数比；建立时自动保持当前装配相位。
- 上下齿轮继续作为独立轨道并保留各自生成参数；上层小齿轮可再次作为主动件，后级啮合按小齿轮自己的齿数计算。
- 自动检查两轴平行度和轴线偏心；轴向可以有高度差，只有真正共轴才建立关系。
- `PMTBindMechanical`、`PMTBindMultiple` 和传动编辑界面均加入中文“同轴刚性或复合齿轮”选项，继续支持一主多从、串联与循环阻止。

### 0.4.4 轨道排序

- 在时间轴左侧轨道名称区域按住并上下拖动，即可调整轨道显示顺序；青色横线表示插入位置。
- 拖动父级轨道时，其全部子级和后代会作为完整子树一起移动。
- 子级只能在同一父级下与兄弟轨道交换顺序，拖动排序不会更改父子关系。
- 根级轨道可以自由前后排序；同级顺序会随3dm文档保存。
- 关键帧区域的水平拖动方式保持不变。

### 0.4.3 分度圆与中文选项

- 齿轮生成时新增“是否输出分度圆/分度线”，默认“是”。
- 直齿、内齿、斜齿和锥齿生成青色分度圆，半径严格为 `模数 × 齿数 ÷ 2`；两齿轮分度圆相切即可确定标准中心距。
- 齿条生成青色分度线，便于与齿轮分度圆定位。
- 分度圆/线放在同一个动画块内部，会随齿轮一起移动和旋转。
- Auto、ExternalGear、InternalGear、Belt、HelicalGear、BevelGear、RackPinion、Normal、Reverse 和综合齿轮类型均显示对应中文名称。

### 0.4.2 齿轮生成修正

- 修复每个齿顶和相邻齿之间的连续重复节点；这些节点会使 Rhino 拒绝挤出或放样，表现为命令结束但没有生成对象。
- 所有齿形在挤出前都会清理无效点并确认轮廓有效、闭合。
- 直齿、内齿、斜齿、锥齿或齿条实体生成失败时，不再直接终止；会回退输出可见的闭合齿形曲线并自动加入时间轴。
- 命令行会显示失败发生在轮廓、挤出、放样、封口、布尔孔或动画块中的哪个阶段。

### 0.4.1 传动网络修正

- 内啮合自动识别不再限制内齿圈必须是从动件：内齿圈主动、小齿轮从动同样可以按正确比例联动。
- 一主多从完成后逐条输出啮合检查结果，便于立即发现中心距、模数、轴向或齿数组合问题。
- 自动拦截把齿条选为主动件的错误操作；当前版本支持齿轮驱动齿条，不会再把齿条误当旋转件。

### 0.4.0 合并功能

- **自动轴孔**：扫描块内圆边，优先选择靠近零件中心且有成对共轴边的孔，自动设置轴心和轴向；也可单独运行 `PMTAutoPivot`。
- **可视化传动图**：视口直接连线显示“主动→从动”和实时比例；面板列表可定位两端、编辑齿数/模数/压力角/相位或删除关系。
- **真实啮合检查**：检查轴平行度、外/内啮合理论中心距、内齿齿数条件和 20° 标准齿少齿根切风险；绿/黄/红直接反映结果。
- **一主多从机构网络**：选中一个主动轨道后，使用 `PMTBindMultiple` 一次选多个从动件。每个从动件仍可成为下一级主动件，循环驱动会被拒绝。
- **动作自动衔接**：模板可选“当前帧”、“所选轨道末尾”或“全部动作末尾”，并可设置间隔帧；往复、回弹、曲柄滑块和四连杆可直接排成连续演示。
- **齿轮生成器合并**：参考 RhinoGears 的渐开线参数，重写为 Rhino 7/8 共用 C#；可生成渐开线直齿轮、内齿轮、斜齿轮、锥齿轮和齿条实体。
- **生成即可动**：新齿轮自动转为时间轴部件，并记录齿数、模数、压力角、厚度、旋向/锥角等参数；后续 Auto 绑定不用重复输入。
- **传动类型扩展**：除外啮合、内啮合和皮带外，加入斜齿、锥齿和齿轮-齿条；齿条位移量由齿轮节圆周长计算。
- 0.3.0 的自动轴孔、可视化关系图、真实啮合检查和四个动作模板全部保留。

## 主要能力

- Rhino 7：`.NET Framework 4.8`；Rhino 8：`.NET 8.0`；同一套源码多目标编译。
- Rhino 停靠面板：播放、暂停、逐帧、首尾帧、拖动时间轴、循环、FPS、起止帧。
- 位移、旋转、缩放关键帧；平滑、线性、阶梯插值；四元数旋转避免欧拉角跳变。
- `平滑：缓入缓出`为起步慢、中段快、到达前减速；`线性：匀速`为恒定速度；`阶梯：保持后跳变`在下一关键帧瞬间切换。
- 自定义轴心和连续轴转角；可输入 `360°`、`720°` 或负角度。
- **组内零件**：对象已经使用 Rhino `Group` 打组时，仍可只选其中一部分建立独立动画轨道。
- **父子层级**：父级运动会传递给所有子级；子级仍可叠加自己的关键帧，可继续建立多级子级。
- **机械约束**：外啮合、内啮合、皮带、斜齿、锥齿、齿轮-齿条和同轴刚性；支持分支、串联并阻止循环驱动。
- 动画数据写入当前 `.3dm`；兼容旧版数据，保存时自动升级为 0.4 数据格式。

## 最快使用流程

### 普通关键帧

1. 运行 `PMTimeline`。
2. 点击“添加部件”，选择一个完整刚性组件。
3. 转动件先点击“设轴心”，捕捉真实轴中心，并选择连续轴 X/Y/Z。
4. 在起始帧插入关键帧。
5. 切到另一帧，用 Rhino Gumball 移动、旋转或缩放部件，再插入关键帧。
6. 连续旋转可在关键帧中输入 `360°`、`720°` 等角度，然后播放。

### 框选移动和任意位置粘贴

1. 右键拖框选择关键帧；`Shift` 继续加选，`Alt` 从已选中减去。
2. 按住任意一个已选关键帧左右拖动，框选的全部关键帧一起移动。
3. 点“复制所选”，再点击目标轨道或在 Rhino 视口选中目标动画物体。
4. 把播放头移到目标起始帧，点“粘贴到目标轨道/帧”。
5. 如果目标帧已有关键帧，新粘贴内容会覆盖该帧，状态栏会显示覆盖数量。

### 已打组物体中只动画一部分

1. 点击“组内零件”或运行 `PMTAddGroupPart`。
2. 只选择需要运动的板件；该选择不会自动扩大为整个 Rhino 组。
3. 可多选若干同步运动的板件，插件会把它们转换成一个独立动画块并保留共同的组关系。
4. 继续卡关键帧；同组其他物体不会被带入这条轨道。

### 建立父子级

1. 父件和子件分别建立轨道，建议先回到起始帧并摆到装配初始位置。
2. 在时间轴中选中**子级轨道**，点击“设父级”。
3. 在 Rhino 视口选择父级动画部件。
4. 父级移动/旋转时子级整体跟随；子级自己的关键帧仍会在继承运动后叠加。
5. 需要解除时选中子级，点击“清除父级”。

### 齿轮自动传动

1. 点击时间轴里的“外啮合齿轮”“内啮合齿轮”或“皮带传动”。
2. 选择主动件；零件处于 Rhino Group 内也只会采用本次选择的对象。
3. 选择从动件。
4. 输入主动/从动齿数；皮带可输入齿数、直径比例或任意等比例整数。齿轮再确认模数，默认值会按当前中心距反算。
5. 只给主动件设置关键帧。普通旋转可直接用 Gumball 绕所选连续轴旋转；需要整圈或多圈时输入 `360°`、`720°`。

快速传动会自动寻找两个零件的轴孔。若零件有多个相似圆孔，请用“设轴心”手动覆盖，或在选中轨道后重新运行 `PMTAutoPivot`。

外啮合齿轮使用：

`从动角 = 相位角 - 主动角 × 主动齿数 / 从动齿数`

内啮合与皮带使用同向比例。可继续把第一从动齿轮设为下一组传动的主动件，形成齿轮链。

### 一个主动件联动整套机构

1. 先选主动齿轮：可以点时间轴里的主动轨道，也可直接在 Rhino 视口选中主动齿轮；两者会双向同步。
2. 点“一主多从/串联”或运行 `PMTBindMultiple`。
3. 生成器制作的齿轮选 `Auto`；普通模型可手动指定传动类型。
4. 在视口中一次选择多个从动部件，按回车。
5. 要继续串联时，再把某个从动轨道选为新主动件，重复上述步骤。

绑定成功后视口会立即显示主从轴心连线和“类型、齿数、比例”文字，但不会移动任何齿轮。内啮合时，直齿轮可作为主动件、内齿圈作为从动件，两者旋转方向相同。
主动齿轮需要在执行命令前选中；从动齿轮在命令进入选择步骤后再选。从动齿轮绑定前无需卡动作关键帧，插件会保留它的当前摆位。

### 同轴复合齿轮继续驱动后级

1. 大齿轮和轴上方的小齿轮分别保持为独立时间轴轨道；若由插件生成，两者会保留各自齿数。
2. 在时间轴中选中先获得动力的下层大齿轮，点“同轴复合齿轮”或运行 `PMTSameShaft`。
3. 在视口选择同轴固定的上层小齿轮；插件会检查轴线并以 1:1 保持当前相位。
4. 再在时间轴中选中上层小齿轮，点“一主多从/串联”，用 `Auto` 选择后级齿轮。
5. 后级角速度按“上层小齿轮齿数 ÷ 后级齿数”计算；同轴关系本身始终是 1:1。

### 生成并自动绑定齿轮

1. 运行 `PMTGearFactory`，选择直齿、内齿、斜齿、锥齿或齿条。
2. 设置齿数、模数、压力角、厚度和轴孔；斜齿增加螺旋角，锥齿增加节锥角。
3. 生成后已自动建立轨道和轴心，不需要再点“添加部件”。
4. 选中主动齿轮，用 `PMTBindMultiple` 选 `Auto`，插件会读取已保存的齿轮参数。

齿条目前作为从动件；齿轮每转一圈，齿条移动 `π × 模数 × 齿数`。

### 衔接多个动作模板

在“动作模板”一行选择放置方式。“接在全部动作末尾”会自动找到当前最后一个关键帧，加上“间隔帧”后生成下一段，因此可以按“齿轮转动→锅盖弹起→平底锅摆动→柜门回弹”连续排序。

## 编译

Windows 环境需要：

- Visual Studio 2022 或 2026；安装“.NET 桌面开发”。
- .NET Framework 4.8 Developer Pack / Targeting Pack。
- .NET 8 SDK / Targeting Pack。
- Rhino 7 和/或 Rhino 8。

0.4.10 发布门禁会同时执行静态/数学回归、Rhino 7 `net48` 编译和 Rhino 8 `net8.0` 编译，三项全部成功才生成双版本安装包。

在 PowerShell 中进入本文件夹后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于：

- `dist\net48\ProductMotionTimeline.rhp`：Rhino 7。
- `dist\net8.0\ProductMotionTimeline.rhp`：Rhino 8。

## 安装

编译后运行 `install.ps1`；也可以在 Rhino 中运行 `PlugInManager`，点击“安装”，选择对应版本的 `.rhp`，然后完全重启 Rhino。

## 当前边界

- 轨道仍使用 Block Instance 保持稳定的对象变换；“组内零件”会把所选板件转换为独立块，但不会把同组其他物体一起转换。
- 齿轮检查是几何/运动学校验，不进行实体碰撞、齿形接触、背隙、受力或动力学仿真。
- 四连杆模板精确求解主动曲柄和输出摇杆；中间连杆几何目前不自动变形/对齐，可在后续关键帧中单独补充。
- 从动件的连续轴转角由约束计算；其位移、缩放或其他剩余旋转仍可卡关键帧。
- 解除父级会停止后续继承，不会自动烘焙原父级的全部历史运动。
- 创建动画部件前建议另存模型；自动转块属于结构性操作，但支持 Rhino 撤销。

更完整的技术说明见 [docs/PLUGIN_DESIGN_CN.md](docs/PLUGIN_DESIGN_CN.md)。
