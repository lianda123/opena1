# WoodJoint Pro 1.0.0（Rhino 7 / 8）

面向激光切割木板拼装设计的参数化榫槽生成器。插件先完整计算布尔结果，成功后才替换原木板；替换时保留对象GUID、图层、颜色、组、名称、UserString和时间轴父子关系。

## 主要命令

| 命令 | 功能 |
|---|---|
| `WJPJoint` | 主命令：选择十字插槽、T形槽、插片榫、简单卡扣或指接榫 |
| `WJPCrossSlot` | 直接进入十字插槽 |
| `WJPTSlot` | 直接进入T形槽，第一块板为接收板 |
| `WJPTabSlot` | 生成接收槽与插入板榫头 |
| `WJPSnap` | 生成带释放缝和锁止口的简单卡扣 |
| `WJPFingerJoint` | 沿选定长度交替生成指接 |
| `WJPAxisHole` | 生成固定孔、转动孔或导向孔 |
| `WJPCalibrationTest` | 生成板厚插槽与2mm钢轴孔公差测试片 |
| `WJPSettings` | 把测试片实测结果保存到当前3dm |
| `WJPLinkFlat` | 手动关联已经解组的3D木板与铺平副本 |
| `WJPUpdateFlat` | 重新同步已关联铺平副本 |

建议Rhino别名：`WJP`→`WJPJoint`，`WJS`→`WJPSnap`，`WJH`→`WJPAxisHole`。

## 基本操作

1. 运行 `WJPJoint`，选择榫槽类型、板厚来源和配合公差。
2. 选择第一块木板。T形槽、插片榫和卡扣中，第一块是接收板。
3. 选择第二块插入板。
4. 插片榫、卡扣和指接榫继续指定第一点；移动鼠标指定第二点。
5. 长度实时按0.5mm吸附并显示临时尺寸，单击后尺寸自动消失。
6. 检查橙色长度线及红/蓝切割体，回车确认；Esc不修改任何对象。
7. 整次操作只生成一个Rhino撤销步骤，按 `Ctrl+Z` 同时恢复两块木板和铺平副本。

## 板厚、公差与测试片

- 默认使用几何实测板厚，也可选1.5、2、2.5、3、4mm或自定义实测值。
- 默认公差：紧配-0.05mm、普通+0.10mm、松配+0.20mm。
- 默认2mm钢轴孔：固定孔1.95mm、转动孔2.10mm、导向孔2.30mm。
- 不同材料、激光功率和焦距会改变实际间隙。先运行 `WJPCalibrationTest`，测试后用 `WJPSettings`保存当前3dm的实测数值。

## 与 WoodSheetLayout 同步

- 若原件和铺平件仍在 `WSL_PAIR_` 配对组，生成榫槽或轴孔时会自动重建铺平实体。
- 若已经解除配对组，先运行 `WJPLinkFlat`，分别选择3D源木板和铺平副本。
- 后续可使用 `WJPUpdateFlat`手动重新同步。
- 表面装饰曲线不会被删除，原有分组保持不变。

## 安全限制

- 仅处理平直、闭合且能识别两张平行主表面的Brep/Extrusion；折弯件不会强制布尔。
- 五类榫槽要求两块木板主表面相交或成角度；近似平行的板会被拒绝。
- 任意一块木板或铺平副本的布尔/变换失败时，本次操作不提交。
- 卡扣为适合首轮激光样件的简单悬臂结构，最终强度仍需通过材料测试验证。

## 安装

完整解压ZIP，右键PowerShell运行 `install.ps1`，或在Rhino `PlugInManager`中安装对应版本的RHP。安装后完全重启Rhino。
