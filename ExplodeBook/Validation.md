# ExplodeBook 2.0.2 测试记录

本次验证日期：2026-10-08。状态：整合测试版，可进行 Rhino 验收；尚无真实产品模型的正确率统计。

## 已完成

- 全部插件源码分别编译为 .NET Framework 4.8 和 .NET 8 的 RHP，目标分别为 Rhino 7 和 Rhino 8。
- 编译 SDK 为 RhinoCommon 7.38.24338.17001、8.35.26251.13001。Rhino 8 SDK 引用 .NET 7 的框架身份，编译器按 .NET 8 引用匹配，产生 CS1701 提示；工程显式按标准多目标方式处理该引用匹配。没有把 RhinoCommon 或系统运行时 DLL 打入安装包。
- 独立规划核心34组测试全部通过，直接执行生产用碰撞/顺序核心，不以源码字符串检查代替几何测试。
- 包括：接触允许、进入接触面受阻、滑动贴面、实体包含、相同实体重叠、交叉重叠、0.001单位薄片、对角连续碰撞、内部件先于盖板、错误盖板先装被拒绝、封闭箱内件受阻、局部人工先后约束、重复顺序、循环顺序、取消、时间预算、真实孔槽、旋转30度插槽、不同尺度和缓存复用。
- 250个固定种子的随机长方体运动用独立解析区间算法对比，不从碰撞核心复制预期结果。
- 150个独立零件的规划包含全部零件；150个接触零件重复规划无需重新执行已缓存的配对碰撞检测。
- 三个 Rhino 7 格式的示例3dm重新读取成功，全部几何有效，Mesh封闭、Brep为实体。它们用于后续原生 Rhino 界面验收。

本环境一次核心微基准：150个独立长方体约15ms；150个接触长方体首次约50ms、缓存后约17ms，配对计算298次减少到0次、缓存命中447次。这些数字仅反映独立数学核心，不包含 Rhino 网格生成、说明页、视口或 PDF，也不是对旧版或真实模型的加速比例。

## 需要在 Rhino 7/8 主程序中完成

| 验收项 | 预期 |
|---|---|
| 安装、重启、命令加载 | 两版本均能正常加载；与旧 ExplodeBook 使用同一插件 GUID |
| 示例01 | 机架→内部件→盖板；说明书和箭头一致 |
| 示例02 | 受阻诊断；不生成成功说明书 |
| 示例03 | 找到板面法线方向；插槽保持可见 |
| A4/A3及纸张单位 | 尺寸、页边距、视口正确；不改变既有纸张单位 |
| 模块与人工顺序 | 内部步骤和模块装入路径均检查；冲突停止输出 |
| 编辑、撤销、删除、取消、失败更新 | 输出正确刷新；旧有效结果在失败时保留；源模型不被移动或删除 |
| PDF | 三维板件、孔槽、字体、编号清晰；缺页或与模型不一致时拒绝导出 |
| 实际产品 | 复核紧配合、手指/工具空间、旋转/弹性步骤和实际稳定性 |

因此不能承诺所有模型零错误，也不能宣称说明书成功率已经提升了某个百分比。改进在实现层面消除了距离猜序、重复几何和强行输出路径；真实成功率必须使用你的代表性模型和 Rhino 主程序测量。

## 2.0.1新增验证

新增三组接触容差回归：远离原点的0.00024mm坐标舍入不再当作超容差穿入；0.02mm真实穿入在0.001mm接触容差下仍失败；接触容差不允许零件向相邻实体内部移动。32组生产核心测试全部通过。

新增局部网格转换、双精度、闭合重算与诊断代码均已分别编译通过Rhino7和Rhino8 SDK。视口标记、原生网格重算、说明页和PDF仍需在Rhino主程序内验收，不把缓存显示网格的离线探查当成新版本已在真实模型生成成功说明书。

## 2.0.2 本次验证

- Rhino 7 net48 与 Rhino 8 net8.0 编译成功，0警告、0错误。插件GUID不变，程序集版本2.0.2.0。
- 34项生产核心回归通过。新增60个远离原点、不同三角细分的旋转板件贴面情况，以及临近面边缘的边界判断。旧的薄片阻挡、真实穿透、封闭壳体、错误顺序仍拒绝通过。
- 当前用户模型61个Brep全部有效且封闭，472个原对象，两份002文件SHA256相同。缓存渲染网格合计50,582三角面；其中B-24与B-46缓存网格有裸边，因此该复核仅是算法诊断，不能作为完整封闭网格路径验收。
- 同一模型数据、0.001mm接触容差，旧生产核心报告36对位置重叠；修正边缘距离判定后报告5对。两次均没有成功计划或正式说明书。
- 用独立Manifold网格布尔与Trimesh点内/最近表面计算核对候选：B-18/B-01、B-49/B-01约0.100mm；B-06/B-15采样最深约0.361mm；B-26/B-19约0.00179mm；B-26/B-20约0.00166mm。这是缓存网格采样估计，不是原Brep精确穿透证明，尤其后两对必须在Rhino新网格中复核。
- 用户要求全部按干涉处理。保持0.001mm接触容差，不把紧配重叠自动豁免，不放宽公差，不将可拆板件合并绕过检测。
- 初次模块顺序写入、基准重选、更新失败报告代码完成复查与双SDK编译；它们的真实文档操作、原生重新网格、Layout与PDF尚未在Rhino主程序运行。
- 诊断3dm副本保留原对象ID、61个实体的有效封闭状态、边界、拓扑数量、顶点、NURBS结点及控制点；仅加编号和候选位置。重新写入3dm会改变部分缓存序列化字节，不宣称文件逐字节相同。
