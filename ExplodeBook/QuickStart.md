# 快速操作 · ExplodeBook 2.0.1

1. 关闭 Rhino，解压安装包；Rhino 7 安装 net48 文件，Rhino 8 Core 运行时安装 net8.0 文件。不要加载两个 ExplodeBook 版本。
2. 先打开 `samples/01_内部零件先于盖板.3dm`，选全部原件，运行 `EBAnalyze`。预期：预装机架 → 内部零件 → 盖板。
3. 运行 `ExplodeBook` 选择 A4/A3，选全部原件。切换 Layout 检查每一步原板件、黄色当前件和安装箭头，再运行 `EBExportPDF`。
4. 打开 `02_封闭结构应报告受阻.3dm`。预期：内部零件受壳体阻挡；不得生成成功的装配说明书。运行 `EBFocus` 点内部件查看，再用 `EBRestore` 恢复。
5. 打开 `03_旋转板件真实插槽.3dm`。预期：自动沿旋转后的板面法线找到插入路径，不把孔的包围盒当成实心阻挡。
6. 用你的真实模型验证：可拆板件保持独立封闭实体，整体群组可以保留。永久固定的组合用 `EBDefineRigid`；可拆组合不要做成单一块实例。
7. 两级装配用 `EBDefineModule` 指定。若模块不能整体装入，检查划分：需要与别件交叉穿插的板件应共同作为一个模块。
8. 指定基准用 `EBSetBase`；手动顺序用 `EBSetPartOrder` 或 `EBSetModuleOrder`。手动方向从最终位置向外指定拆出方向；安装箭头自动取反。检查不通过时先修正模型或约束。

升级旧模型时，若旧版顺序妨碍重新分析，选全部原件运行 `EBAutoOrder`。旧版未记录的 Layout 需单独清理。

这是整合测试版，三个示例已生成并验证实体有效，但还没有在 Rhino 主程序里完成示例出图、PDF 和真实产品装配验收。检查通过表示网格直线路径通过，不包含旋转、弹性和施力验证。

## 从2.0.0升级后

关闭 Rhino 后替换安装。打开原模型，先运行 `EBRestore`，再选全部原件运行 `EBAnalyze`。原有指令保持不变。若失败，看左上角具体原因或运行 `EBReport`；只标记已经定位的零件，不需要按旧截图逐个修复全部板件。

若安装包附有 `ModelCheck-002.md`，可查看本次模型检查。实际网格和拼装路径仍需在 Rhino 内重算并核对。
