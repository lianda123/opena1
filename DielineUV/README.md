刀模贴图助手 DielineUV 0.4.20

Windows 安装
1. 完整解压到固定目录。在 Rhino 输入 PlugInManager，点击“安装”。
2. Rhino 7（含 7.1）安装 Rhino7/DielineUV.rhp。
   Rhino 8 默认 .NET 模式安装 Rhino8/DielineUV.rhp（Rhino 8.21 或更新版本）；
   Rhino 8 的 .NET Framework 模式安装 Rhino7 目录中的 .rhp。
3. 升级后完全退出并重启 Rhino。输入 DielineUV，标题应显示 0.4.20。
   原有 manifest.json 和 mapping.3dm 可以继续使用。

macOS 安装
双击 Mac 中相应主版本的 .macrhi，或拖到相应 Rhino 的 Dock 图标，重启 Rhino。
两版本同机使用时，将 Rhino 8 插件包放在 Rhino 8 专用插件目录，避免覆盖共享安装。
https://developer.rhino3d.com/en/guides/rhinocommon/plugin-installers-mac/


通用模型导出
1. 保持原模型中已正确显示的贴图。运行 DielineUV，选择
   “导出通用模型（GLB／OBJ，烘焙 UV）”。已有绑定和 PNG 可以继续用。
2. 选择导出范围，再选保存位置。四种范围为：
   “导出全部已贴图零件”；“选择需要导出的已贴图零件”；
   “导出全部零件（包含未贴图零件）”；“仅导出未贴图零件”。
   后两项不要求未贴图零件先绑定刀模或导入 PNG。
   每次生成新的“DielineUV_通用模型_...”文件夹，不覆盖以前的输出。
3. 优先在目标软件导入 model.glb。该文件内含独立零件、标准网格 UV、材质及 PNG，
   不依赖 Rhino 的第 32 通道或本机 AppData 图片路径。
4. 不支持 GLB 的软件使用 model.obj。必须保留同目录的 model.mtl 与 textures 文件夹，
   不要只复制 OBJ。OBJ 与 GLB 均以米为单位、Y 轴向上，导入时按此设置。
5. 颜色、背面、侧边沿用实际使用的合成图集；不要替换成原始刀模 PNG。
   透明件的遮罩会合入 GLB 的 Alpha，OBJ 则同时输出 map_d 图片。
   具体透明显示及灯光、反射效果由目标软件决定。
6. 每个零件独立保存，原件编号写入 GLB 节点 extras.source_id 和 parts.json。
   该数据也可用于网页装配对应关系。
7. 通用导出只读取当前模型，不修改原件、绑定、材质或原始刀模。
   原始刀模模板的导出功能仍用于二维绘图。普通 Rhino“导出”旧实体不会自动经过此流程，
   跨软件传递时请使用本节的新菜单及其生成的 GLB 或 OBJ。
8. 已贴图零件仍按插件 UV 导出；如已编辑原件形状而未更新映射，或颜色与透明遮罩
   通道不一致，将中止导出并提示。未贴图零件按当前对象或图层材质的基本颜色和
   透明度导出，不需要图片和 UV，也不会套用其他零件的图案。
   三维零件范围为曲面、多重曲面、拉伸体和网格；二维刀模线框等曲线不参与导出。
   未经插件贴图的对象使用基本颜色材质，不烘焙第三方着色器或其他程序材质效果。

导出和绑定
1. 打开包含三维原件和二维刀模的同一模型，使用毫米单位。运行 DielineUV，
   选“导出刀模框模板（可连续导出）”，选择包住二维刀模的闭合矩形外框。
   外框大小按实际刀模决定，边平行世界 X、Y 轴；三维原件可以在外框之外。
2. 可识别排版关联，或选择原件和刀模进行自动／手动绑定。
   自动模式：选原件，选对应的二维闭合轮廓及孔槽，回车确认。
   多个匹配方向时，用对应编号确认，点“下一个方向”切换，回车采用。
   自动失败会保留当前选择，转入手动，各点三个对应角点。
   同一次绑定中可随时切换“自动对齐”和“手动绑定”。
3. 绑定成功后自动隐藏原件和刀模。命令行提供：
   “刀模标绿／隐藏刀模”：改变已绑刀模的临时显示。
   “查看已绑／继续绑定”：显示原件及刀模上的对应编号，返回后继续选件。
   “撤回上一件”：取消最近一次成功绑定，恢复该原件与刀模，可连续撤回。
4. 选原件的提示处回车进入保存位置选择。若误敲回车，在保存窗口点“取消”，
   自动返回绑定并保留全部已绑记录，可继续添加或撤回。
   真正退出本次绑定，在选原件提示处按 Esc。
   导出、退出或报错时均恢复本次临时隐藏的对象，不改变原材质或刀模颜色。
5. 导出成功后可选“继续导出下一个刀模框”，重新选外框并绑定，数量不限制。
   下一框会沿用保存位置，但重新建立本框的零件对应关系。
   每框生成独立的 DielineUV_... 文件夹；外框已命名时会带上外框名称。
   完整输出后才成为可用模板，报错不会覆盖已完成的项目。
   点“完成导出”结束；以后再次运行命令仍可继续导出其他外框。
   下一框取消绑定时，前面已导出的模板仍然有效。

绘制和更新 PNG
1. Photoshop 打开 template.png，或 Illustrator 打开 template.svg。
   保持完整画板边界和零件位置，隐藏参考线后导出 RGB PNG。
   分辨率可以改变，长宽比应一致，关闭按内容裁切。
2. DielineUV →“导入／更新 PNG 贴图”，选择 PNG 及对应 manifest.json。
   manifest.json 和 mapping.3dm 必须来自同一次导出并放在同一目录。
   一个模型可以有多个项目文件夹。每张 PNG 选择所属刀模框的 manifest.json；
   建议把画好的 PNG 放回该框文件夹，导入时可直接使用同目录的对应关系。
   不同框可设置不同板材、侧边颜色、单双面或透明材质，按框分别导入／更新。
3. 选择印刷方式：
   一个刀模框统一选择一次，所有零件自动沿用相同的单双面、背面和侧面设置。
   “沿用此刀模框上次设置”：以第一件为准，更新图案时统一沿用；首次按双面。
   “整个刀模框：双面同图”：平板的两侧大面使用同一图案。
   “整个刀模框：单面印刷”：正面分配图案，另一大面使用背面材质。
   “整件贴图”：兼容以前把 PNG 分配到所有表面的效果。
4. 单面印刷首次只需在第一个平板原件上选择印刷侧（Ctrl+Shift 点面；
   Mac 用 Command+Shift），点选一次即可。其余平板根据刀模方向及板厚位置自动选择，
   不按世界坐标机械套用同一方向，因此三维原件可以朝向不同。
   分割的大面按板厚位置归入同一侧，包含底面的浅槽；不依赖曲面法向或翻转标记。
   印刷侧随模型保存，更新 PNG 不必重选。
   需要换正反面，选“单面印刷并重选第一件印刷侧”。
5. 侧面与背面分别选择材质：保留当前／上次、棕色、自定义颜色、密度板原色、
   木板原色，或其他 PNG/JPG 材质。背面还可选择“与侧面材质相同”。
   两张板材图片已嵌入插件，无需另外拷贝。插件在内部生成图案、背面和侧边的
   分区贴图，统一赋予原实体，绕开 Rhino 逐面材质通道；原 PNG 和模板不会改写。
   “沿用当前材质”取当前颜色或颜色纹理，不包含金属反射等复杂着色参数。
   查看效果请切换 Rhino 渲染显示模式。
6. 改图可重复导入 PNG；只改颜色或单双面可使用主菜单
   “调整现有贴图的单双面／背面／侧边材质”。选择项目 manifest.json 后，
   统一调整该框内全部零件。已有 PNG 会自动沿用。
   0.4.12 的旧对象若无法读取原 PNG 路径，会要求补选一次。
   一个刀模框内不再逐件确认或混用板材；不同外框可以使用不同材质。
7. 侧面或背面材质变更时重新生成内部分区贴图，正面图案不必重新绘制。
   几何位置／形状或刀模排版改变时，仍需重新导出模板。
   保存模型可勾选“保存纹理”；跨电脑传递时同时带上项目文件和贴图。

已有中间层刀模的折弯件
1. 保留原三维实体和已有二维刀模，不必重新按外表面制作刀模。
   DielineUV → 导出刀模框模板（可连续导出） → 选外框 →
   “折弯件：绑定已有中间层刀模（允许拉伸）”。
2. 点选三维原件，再选择对应二维刀模的封闭外轮廓，回车。
   可以选多条 Make2D 线及孔槽，外轮廓需能连接成闭合线。
3. 在原件上用 Ctrl+Shift（Mac 用 Command+Shift）选实际要印图的一侧连续曲面，
   包括相连的直面和弯面，回车确认。不要把背面和厚度侧面一起选入。
   这一步选实体上的实际印刷表面，不选偏移后的中间层曲面，不需点六个定位点。
4. 对四段封闭轮廓拉伸形成的等厚弯板，优先沿两侧轮廓的中线计算累计长度；
   圆弧板、S 形条带可使用此路径。其他可展开曲面按实际印刷表面展开，
   再沿两个排版方向伸缩到已有刀模范围；不会改变原件的几何形状或制造尺寸。
5. 视图显示两边的 1、2、3 对应编号和绿色展开轮廓。
   命令行显示方向、伸缩比例和轮廓拟合差。用“下一个方向／上一个方向”
   切换旋转与镜像，回车采用。对称矩形也需确认图案朝向。
   这是允许图案拉伸的视觉映射；复杂孔槽及多个折弯的局部位置可能近似。
6. 插件会识别相对的背面；识别不到时可补选背面。厚度侧面留给侧边材质。
   若跳过背面，单面图案的其余面采用非印刷面材质；要使用双面图案，
   带厚度实体需要记录背面，不能跳过。
7. 成功后自动隐藏原件与刀模。可切换“自动对齐”“手动绑定”“折弯刀模”，
   在同一外框混合绑定平板和折弯件；保留撤回、标绿和取消保存后继续绑定。
   导出时会恢复显示，并把对应关系写入 manifest.json 和 mapping.3dm。
8. 绘图后按同一个项目导入 PNG。单面图案分配到绑定时选择的印刷曲面；
   背面和厚度侧边分别使用整框设置。双面图案分配到两侧曲面，侧边独立。
   要反换印刷侧，可在调整材质时选择“单面并重选首件印刷侧”。
   后续只换 PNG 无须重新绑定；改变刀模排版或原件几何后需重新导出。
9. “展开折弯件并记录对应关系”仍是按表面生成新展开件的原流程。
   已有中间层刀模请走本节的新绑定流程，以记录独立背面和伸缩关系。
   球面等双曲率曲面不在通用展开范围内，闭合筒面需先切开接缝。

透明件贴图（独立选项）
1. DielineUV → “透明件：导入／更新 PNG”，选择 PNG 和对应项目模板。
   也可在普通导入的印刷方式中选择“透明件贴图（统一底色／透明度）”。
2. 一个窗口为整个刀模框统一设置：图案单／双面、底色和透明度 0～100%。
   两面无图区域和厚度侧边使用同一底色、同一透明度。
   颜色图片保持原色，独立不透明度遮罩控制可透视区域；调高透明度不会把颜色混白。
   遮罩白色保留表面、黑色透出背景；整件材质的玻璃透明度保持 0，避免连图案一起消失。
   0% 时关闭透明遮罩，底材和图案均不透明；100% 时无图区域完全透明，实色图案仍保留。
   图案的实色区域保持不透明，不会随底材一起变透明；抗锯齿边缘保留覆盖度。
3. 图片背景可选自动识别、透明背景 PNG、白底 PNG。
   自动模式优先使用 PNG 的透明背景，否则按白底处理。
   白底模式把接近纯白的像素当作无图区域；需要白色图案时，请选择透明背景 PNG。
   如果选了透明背景模式，但图片没有透明背景且含白色，插件会询问是否去白底。
   去白底会把白色区域当作透明底材；保留白色会把它视为不透明图案。
   导出图片前隐藏刀模参考线，避免参考线被当作图案印到零件上。
4. 底色和透明度可以再次调整：主菜单“调整现有贴图的单双面／背面／侧边材质”，
   选原 manifest.json，然后选透明件。原 PNG 会沿用，设置会随模型保存。
   普通导入中选“沿用此刀模框上次设置”时，也会保留透明件模式并预填设置。
5. 透明件同样适用于本版新绑定的折弯实体。图案沿折弯坐标贴合，背面和侧边
   仍使用相同透明底色。查看时切换到“渲染”显示模式。
   本功能使用独立颜色／透明遮罩，透明遮罩与图案使用相同 UV 通道，折射率设为 1，
   用于直观预览透视效果，不模拟真实玻璃折射。旧项目无需重绑，重新导入 PNG 即可升级材质。

适用范围与验证
0.4.20 增加导出全部零件（含未贴图）及仅导出未贴图零件两种范围。
未贴图零件保留独立对象、基本材质颜色和透明度；混合导出不改变已贴图零件的 UV。
0.4.19 增加带标准逐顶点 UV 的 GLB / OBJ 导出、相对材质路径与自包含图片。
通用导出的坐标方向、单位、UV 接缝、纹理引用和透明像素均有回归检查；GLB 还通过 Khronos 校验。
0.4.18 修正 0.4.17 将整体透明度固定成 100% 及遮罩黑白方向错误的问题。
应用前会读取 Rhino 实际显示材质，核对整体透明度与遮罩是否保存成功。
保留 0.4.16 的字体修复、连续多刀模框导出，以及已有折弯绑定。
保留 0.4.14 的内部贴图分区，不使用此前反复失败的逐面材质通道。
单面与独立背面适用于带厚度的曲面实体、拉伸体及多重曲面。
零厚度曲面没有独立实体背面，立体网格仍需使用“整件贴图”。
拉伸体在应用分区贴图时会转换为同形的多重曲面，原位置和形状不变。
构建检查覆盖 Rhino 7/8 编译、Rhino 7.0 SDK 引用、板厚分侧、中线长度、
旋转镜像及伸缩拟合、透明像素与遮罩极性／原色保留、多框文件隔离与失败恢复、
嵌入板材图片和压缩包完整性。
按用户要求未启动本机 Rhino 实机验证；自动检查不能代替实际选面及渲染验证。
