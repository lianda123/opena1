刀模贴图助手 DielineUV 0.4.1

Windows 安装
1. 完整解压到固定目录。在 Rhino 输入 PlugInManager，点击“安装”。
2. Rhino 7 选择 Rhino7/DielineUV.rhp。Rhino 8 默认 .NET 模式选择
   Rhino8/DielineUV.rhp（针对 Rhino 8.21 或更新版本编译）；若 Rhino 8 使用
   .NET Framework 模式，选择 Rhino7 目录中的 .rhp。
3. 升级旧版时重新选择新版 .rhp，然后完全退出并重启 Rhino。
   输入 DielineUV，确认标题显示 0.4.1。

macOS 安装
1. 双击 Mac 目录下与 Rhino 主版本相同的 .macrhi，或拖到该版本的 Dock 图标。
2. 完全退出并重启 Rhino。两版同机使用时，把 Rhino 8 的 DielineUV.rhp 包
   放入 Rhino 8 的专用插件目录，避免覆盖共享安装。参见 McNeel 的说明：
   https://developer.rhino3d.com/en/guides/rhinocommon/plugin-installers-mac/

实际项目使用步骤
1. 打开包含三维原件和二维排版的同一个 .3dm。原件应可编辑，不能处于锁定状态。
2. 运行 DielineUV，选择“导出当前项目模板”。在平面图上点选包住要贴图零件的
   闭合矩形线。矩形须平行于世界 X、Y 轴，大小不限 A3。
3. 用配套排版插件生成的排版件，选择“识别排版关联”。如果找不到对应关系，
   平板可选择“手动绑定平板（三对定位点）”。点选一个三维原件，再点选或框选它的
   刀模轮廓，回车确认。先在原件同一大面上依次点三个角点，再按同样顺序点刀模的
   对应角点。角点必须不同且不共线。可在透视视图点原件，在顶视图点刀模。
   绑定完成后，继续点选下一个原件，或者按回车导出。已有的普通组可以保留。
4. 把导出的 template.png 放入 Photoshop，或在 Illustrator 中打开 template.svg。
   绘图后隐藏参考线，按完整画板导出 RGB PNG。可以改分辨率，保持长宽比、
   画板边界及零件位置；关闭按内容裁切。保留同一目录的 manifest.json 和 mapping.3dm。
5. 回到生成模板的 .3dm。运行 DielineUV，选择“导入／更新项目贴图”，
   选本次导出的 manifest.json，再选绘制好的整张 PNG。切换到“渲染”模式查看。
6. 同一张刀模可含多个零件。改图时直接重复第 5 步；如果改了外框、排版位置，
   或三维原件移动、重建，重新导出模板。保存模型时可勾选“保存纹理”。

折弯件使用步骤
1. 运行 DielineUV，选择“展开折弯件并记录对应关系”，点选三维原件。
2. 开放曲面可以整体展开。带厚度实体需要以子对象方式选择要印图的一侧表面，
   包含相连的直面和折弯面，不选背面及厚度侧面。回车确认。
3. 指定展开件在世界 XY 平面的排版位置。插件同时保存网格点与三维原件的对应关系，
   不需要手动点六个定位点。可对这个展开件做整体移动、旋转或镜像，不能缩放、
   炸开、剪切或重建。多个原件分别执行一次，再放到同一个矩形外框里。
4. 按上面的“实际项目使用步骤”导出模板，选择“识别排版关联”。
   导出的 calibration.png 是带坐标编号的彩色格子图，可以先按项目贴图导入，
   检查弯曲处的连续性和方向，再制作正式图案。
5. 对应关系随 .3dm 中的展开对象保存。后续只改 PNG 无须重新绑定。

折弯件范围
支持可无变形展开的连续表面，如平面折角、圆柱/圆锥弯面和相连直面。
检测到断开、重叠、编号丢失或明显伸缩时会停止。闭合筒面需先切开接缝。
球面等双曲率曲面不在本流程范围内。
本版按所选印图表面展开，可能与按中性层或 K 系数生成的旧刀模尺寸不同。
请使用本版生成的模板绘图；旧展开件缺少逐点对应数据，需重新生成，不能只换 PNG。
材质赋予整个原三维对象，未选的背面和厚度侧面不保证贴图效果。
常规平板仍可自动识别或用三对点手动定位。样例工具保留在独立菜单。
