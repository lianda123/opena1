# WoodCheck 1.0.0

面向激光切割木质拼装产品的 Rhino 装配与可制造性检查插件，兼容 Rhino 7 和 Rhino 8。

## 一键检查内容

- **穿模/碰撞**：先用边界框快速筛选，再通过实体布尔交集计算真实重叠体积。
- **槽深不足**：识别木板多段线外轮廓中的 U 形插槽，检查槽深是否低于设定值。
- **孔轴不同心**：自动寻找接近当前钢轴直径的圆孔，检查相邻平行轴孔的中心线偏移。
- **薄弱位置**：检查孔到板边、孔与孔之间的剩余木料，以及过短加工边。
- **重复曲线**：识别公差范围内重合的曲线，防止激光重复走刀。
- **断开曲线**：检查未闭合切割轮廓；“雕刻/刻线/engrave/etch/mark”图层中的开放线不会误报。
- **无效几何**：提示需要先用 Rhino `Check` 修复的坏对象。

插件只新增 `WoodCheck_错误`、`WoodCheck_警告`、`WoodCheck_提示` 三个标记图层，**不会改动原模型、打组、图层或颜色**。

## 命令

| 命令 | 作用 |
|---|---|
| `WoodCheck` | 选择部分零件后执行检查，支持打组选择 |
| `WCCheckAll` | 检查当前文件全部可见、未锁定对象 |
| `WCSettings` | 修改板厚、轴径、槽深、同心公差等参数 |
| `WCLocate` | 输入 `E001`、`W002` 等问题编号，选中对应源对象 |
| `WCClearMarkers` | 清除问题点和文字标记，不删除原模型 |

## 默认木质产品参数

| 参数 | 默认值 |
|---|---:|
| 名义木板厚度 | 2.00 mm |
| 钢轴直径 | Ø2.00 mm |
| 最小槽深 | 4.00 mm |
| 孔轴同心允许偏差 | 0.15 mm |
| 最小剩余壁厚 | 1.00 mm |
| 最小加工特征 | 0.50 mm |
| 断口首尾间隙 | 0.20 mm |
| 最小碰撞体积 | 0.01 mm³ |

运行 `WCSettings` 可适配 1.5 / 2 / 2.5 / 3 mm 木板及其他轴径。参数在当前 Rhino 会话中有效。

## 使用方法

1. 完全解压对应 ZIP。
2. Rhino 7 使用 `net48/WoodCheck.rhp`；Rhino 8 使用 `net8.0/WoodCheck.rhp`。
3. 在 Rhino 中运行 `PlugInManager`，点击“安装”，选择对应 `.rhp`；也可右键运行 `install.ps1`。
4. 重启 Rhino，输入 `WoodCheck`。
5. 选择组装模型和切割曲线，按 Enter 开始检查。
6. 根据红色/橙色标记修复；输入 `WCLocate` 可按编号选中问题源对象。

## 检查边界

- 碰撞检查要求对象可转换为有效封闭 Brep；开放曲面不参与实体重叠体积计算。
- 槽深检查针对由直线多段线构成的 U 形开口槽；自由曲线槽会跳过，避免误报。
- 自动孔轴检查属于装配启发式检查：只比较接近设定轴径、方向平行、中心线距离在搜索半径内的不同零件圆孔。
- 插接处若设计上允许材料重叠，应在建模阶段完成真实开槽，否则会按碰撞报告。

## 编译

Windows 需要：

- .NET 8 SDK
- .NET Framework 4.8 Developer Pack

```powershell
cd WoodCheck
.\build.ps1 -Configuration Release
```

输出：

- `dist/WoodCheck-1.0.0-rhino7.zip`
- `dist/WoodCheck-1.0.0-rhino8.zip`
- `dist/WoodCheck-1.0.0-rhino7-rhino8.zip`
