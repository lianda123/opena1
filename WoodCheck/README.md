# WoodCheck 1.1.0（精简版）

面向木质拼装产品的 Rhino 装配检查插件，兼容 Rhino 7 和 Rhino 8。本版只保留三项最常用检查，减少误报和操作步骤。

## 三项检查

| 快捷命令 | 检查内容 | 问题标记 |
|---|---|---|
| `WCC` | 实体穿模与真实碰撞体积；使用实体布尔交集计算重叠体积 | 红色，编号 `E001...` |
| `WCA` | Ø2mm 附近轴孔不同心；比较不同木板中平行轴孔的中心线偏移 | 橙色，编号 `W001...` |
| `WCD` | 重复曲线与激光重复走刀；识别公差范围内完全重合的曲线 | 黄色，编号 `I001...` |

`WoodCheck` 会对选中对象一次运行全部三项；`WCCheckAll` 会检查当前文件全部可见、未锁定对象。

## 保留功能

- `WCLocate`：输入 `E001`、`W001` 或 `I001`，自动选中对应的源对象。
- `WCClearMarkers`：删除红色、橙色、黄色问题标记。
- `WCSettings`：修改最小碰撞体积、目标轴孔直径和同心允许偏差。
- 插件只新增问题点和文字标记，不移动、删除或修改原模型。
- 不修改原有打组、图层、对象颜色和图层颜色。

## 默认参数

| 参数 | 默认值 |
|---|---:|
| 最小真实碰撞体积 | 0.01 mm³ |
| 目标钢轴孔直径 | Ø2.00 mm |
| 轴孔候选范围 | Ø2.00 ± 0.60 mm |
| 孔轴同心允许偏差 | 0.15 mm |
| 不同心搜索半径 | 3.00 mm |

## 推荐使用方法

1. 检查装配实体：输入 `WCC`，选择需要比较的实体零件并回车。
2. 检查轴孔：输入 `WCA`，选择含 Ø2mm 附近通孔的木板实体并回车。
3. 检查激光曲线：输入 `WCD`，选择准备导出的切割曲线并回车。
4. 输入 `WCLocate` 和问题编号，定位并选中源对象。
5. 输入 `WCClearMarkers` 清除标记；原模型始终保持不变。

每次运行检查命令会先清除上一次的 WoodCheck 标记。需要同时查看三类问题时，直接运行 `WoodCheck`。

## 检查边界

- 碰撞检查只处理能转换为有效封闭 Brep 的实体；开放曲面不会计算体积。
- 碰撞结果来自 RhinoCommon 实体布尔交集和体积计算，不使用包围盒体积冒充真实碰撞体积。
- 轴孔检查识别木板实体平面主面上的圆形内孔，比较不同零件、方向近似平行的孔轴线。
- 重复曲线检查比较长度、包围盒及双向采样距离；只报告完全重合的曲线，不再检查开放曲线。

## 安装

1. 完全解压 ZIP。
2. Rhino 7 使用 `net48/WoodCheck.rhp`；Rhino 8 使用 `net8.0/WoodCheck.rhp`。
3. Rhino 输入 `PlugInManager`，点击“安装”，选择对应 `.rhp`。
4. 完全重启 Rhino，输入 `WoodCheck`、`WCC`、`WCA` 或 `WCD`。

## 编译

自行编译需要 .NET 8 SDK 与 .NET Framework 4.8 Developer Pack：

```powershell
cd WoodCheck
.\build.ps1 -Configuration Release
```

输出：

- `dist/WoodCheck-1.1.0-rhino7.zip`
- `dist/WoodCheck-1.1.0-rhino8.zip`
- `dist/WoodCheck-1.1.0-rhino7-rhino8.zip`
